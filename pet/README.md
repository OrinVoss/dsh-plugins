# dsh-pet —— DSH 桌面宠物

一只住在浮层里的小家伙。它跟着**皮肤**换色，跟着 **Agent** 换表情，能被点、被拖、被换。

```
                     ┌──────────── 浏览器 ────────────┐
  /pet-api/activity  │  shell.overlay → 宠物浮层       │
   （每 1.2s 轮询）  │   ├─ 6 种宠物（内联 SVG）       │
        ▲            │   ├─ 状态动画（CSS keyframes）  │
        │            │   └─ 气泡 / 小跟班徽章          │
  ┌─────┴─────┐      │  设置 → 通用 → 宠物行            │
  │ host.js   │      └────────────────────────────────┘
  │ 只读事件  │
  │ 折叠成快照│ ← session/event、api-session/status、agent/error、subagent/*
  └───────────┘
```

## 六只宠物

| id | 名字 | 造型 | 说明 |
|---|---|---|---|
| `cat` | 像素猫 | 四足 / 尖立耳 / **虎斑额纹** / **粉鼻头 + ω 嘴** / **细弯胡须** / **带环纹的粗卷尾** | 默认那只，爱打盹 |
| `shiba` | 柴犬 | 四足 / **宽圆外斜耳** / **背上一圈粗卷尾** / **大口鼻 + 黑鼻头 + 舌头** / **红项圈** | 卷尾巴的狗子 |
| `koi` | 锦鲤 | 侧游 / 大双叶尾鳍 / 锦斑 | 斑点跟随皮肤强调色 |
| `slime` | 史莱姆 | 软体 + 水珠 | 一弹一弹的 |
| `robot` | 小机器人 | 方块 | 天线 LED 跟随皮肤强调色 |

所有四足宠物脚下都有一层**接地阴影**，不会像贴纸一样飘在界面上。

> 猫和柴犬共用同一个四足骨架，但**关键特征全部不同**：耳朵造型（尖立 vs 宽圆外斜）、
> 尾巴（带环纹的粗卷尾 vs 压在背上的整圈卷尾 + 白尖）、口鼻（粉鼻头 + ω 嘴 vs 突出的大口鼻 +
> 黑鼻头 + 张嘴吐舌）、以及狗独有的**红项圈**。自检里有两条专门卡这些：一条比对两只的
> 关键参数与造型差异字符数下限，一条锁住猫自己的虎斑 / 粉鼻 / 曲线胡须 / 接地阴影。

造型都是**内联 SVG**（CSP 下不能外链图片），可动部位用固定类名标记
（`.pet-body` / `.pet-tail` / `.pet-tent` / `.pet-eye` / `.pet-led` / `.pet-glow`），
由 CSS 按状态驱动——所以加一只宠物只要往 `PETS` 里加一条、必要时给 `RIGS` 加个函数。

## 六种状态

| 状态 | 触发（宿主事件） | 表现 |
|---|---|---|
| `idle` | 无 | 呼吸、甩尾、偶尔眨眼 |
| `work` | `api-session/status` 有会话在跑，或有未结束的 `tool/call` | 快速起伏 + 对话框显示**正在做的事**（翻文件 / 看图 / 敲命令 / 改代码…，见下表） |
| `wait` | `approval/asked` 未 `decided` | 上下点头 + 气泡「等你点头」 |
| `done` | `turn/end` 之后 5.2 秒内 | 跳一下 + 三颗星星 |
| `error` | `agent/error`、或 `tool/result` 带 `isError`，6.5 秒内 | 左右抖 + 冒烟 + 「呜…出错了」 |
| `sleep` | 90 秒没有任何动静 | 闭眼 + 飘 Zzz |
| `pat` | 你点它 | 跳一下 + 冒爱心 + 「嘿嘿」 |

优先级：**等待授权 > 报错 > 干活 > 收工 > 摸头 > 打盹 > 空闲**。
页面隐藏时停止轮询；静默模式或系统「减少动态效果」下动画全部关掉。

### 对话框说的是人话

气泡**绝不直接吐工具原名**（`read_image` 这种）。`toolLabel()` 先把工具名翻成一句动作：

| 工具 | 气泡 |
|---|---|
| `read` / `read_image` | 翻文件… / **看图…** |
| `edit` / `write` | 改代码… / 写文件… |
| `pwsh` / `bash` / `shell` | 敲命令… |
| `glob` / `grep` | 翻目录… / 找东西… |
| `web_search` / `web_fetch` | 搜网页… / 抓网页… |
| `subagent` / `send_message` | 派小弟… / 传话… |
| `todo_write` / `ask_user_question` / `present` | 列清单… / 问你… / 交作业… |

认不出来的名字按关键词归类（含 `image`/`vision`/`screenshot` → 看图，含 `search`/`find` → 找东西…），
实在认不出才兜底成「忙活着…」——**任何时候都不会冒出一串英文原名**。
MCP 工具名（`mcp__server__tool`）会取最后一段再归类。

### 对话框的形状

是一只**带小尾巴的对话框**（不是圆角信息卡）：小尾巴由一个旋转 45° 的方块构成，
底色 `background:inherit` 跟着气泡走，边框只留朝外的两条边，所以和气泡连成一体。
宠物贴到窗口顶部（`x/y` 自由位置 `y < 150`，或停在右上/左上角）时，气泡**自动翻到下方**、
尾巴朝上，不会顶到标题栏。

## 交互

- **点一下** = 摸摸头；**双击** = 换下一只；**按住拖** = 放到任意位置（记住坐标）。
- **大小随便调**：一处**步进胶囊**（规格照抄外壳「正文字号」那一行：36px 高、圆角 `md`、
  `bg-module-platform` 底，数值居中，**hover / 聚焦时才露出右侧的上下小箭头**，按住箭头连发），
  范围 `28–200px`；旁边四个快捷键「小 40 / 中 64 / 大 96 / 巨大 140」。
  旧存档里的 `small / medium / large` 会自动迁移成像素值。
- 右下角徽章 `×N` 表示当前派出了几个子代理（`subagent/start|end`）。
- 悬停有 tooltip：`像素猫 · 等级 3 · 回合 4 · 工具 11 · 128k token`。

### 会走动，不是原地抖

| 骨架 | 走动方式 |
|---|---|
| 猫 / 柴犬 | **踱步**：朝随机目标点走几步，到了歇 1.6–5 秒再挑下一个点 |
| 锦鲤 | **滑行**：两个方向的正弦叠加（看着像在水里绕圈游），换向时**左右翻面** |
| 史莱姆 | **跳**：一段抛物线小跳，落地歇 0.9–2.6 秒 |
| 小机器人 | **飘**：慢慢漂到目标点，带悬停起伏 |

- 运动只是给浮层根节点加一个 `translate3d` 偏移，**"家"始终是你定的那个点**
  （角落或拖到的位置），可走范围围着家、贴着视口边——`homeBounds()` 会把范围夹进屏幕。
- 只在**空闲**时走：干活 / 等你点头 / 报错 / 打盹 / 刚摸头 / 正在拖 时一律不动。
- 设置行里有「**走动**」开关；静默模式与系统「减少动态效果」下自动停（`motionEnabled()`）。
- 拖拽时会**先把偏移归零再量坐标**，所以抓起来不会跳；松手后重新从"家"出发。

## 跟随皮肤

不跟 `dsh-skins` 直接耦合：宠物读的是皮肤暴露在 `body` 上的 `--dsw-skin-accent`
（`dsh-skins` 的 93 个 token 之一）。所以在设置里换皮肤，锦鲤的斑点、水母的伞盖、
机器人的 LED 会立刻跟着换色；关掉设置行里的「跟随皮肤」就用各自的固有色。

## 安装

本包是**组合包（bundle）**。profile（`~/.dsh/profiles/desktop`）三处：

1. `package.json` 的 `dependencies`：
   ```json
   "dsh-pet": "link:C:/Users/17040/.dsh/plugins/pet"
   ```
2. `package.json` 的 `dsh.profile.bundles` 里列出 **`dsh-pet`**。
3. `cordis.patch.yml` 里**不要**再 insert `id: pet`——加载行由本包的
   [`cordis.patch.yml`](cordis.patch.yml) 声明，同一 id 插两次会加载两遍。

装完重启桌面端：侧栏「插件」页会出现「桌面宠物」卡片，右侧浮层里出现宠物，
设置 → 通用 里多出「宠物」一行。

## 宿主接口

| 路由 | 说明 |
|---|---|
| `GET /pet-api/activity` | 活动快照：`running / activeTools / lastTool / awaitingApproval / lastError / turns / toolCalls / subagents / tokens / recent[8]`，另外回带 `events`（成功挂上的监听）与 `eventFailures`（本部署里不存在的事件名）。 |

宿主半边**只读**：不注册工具、不写任何会话数据、不拦截任何 waterfall（既不可能
改变 Agent 行为，也不可能拖慢它）。状态全在内存，宿主重启即清零。

## 对外服务

客户端以 `pets` 服务暴露运行时，别的插件可以：

```js
ctx.pets.list()                  // [{ id, name, hint, swatch }]
ctx.pets.get()                   // 当前宠物 id
ctx.pets.setPet('koi')           // 换一只
ctx.pets.patch({ size: 'large', quiet: true, corner: 'bl' })
ctx.pets.getPrefs()              // 完整偏好
ctx.pets.subscribe(fn)           // 返回退订函数
```

## 已知限制与下一步

- **还没有喂养/成长**：目前只有「等级 = 累计 token / 5 万」这一个数字（宿主重启即清零），没有食物、亲密度、换装背包。
- **子代理只显示计数徽章**，还没有「每派一个子代理就多一只小跟班站一排」。
- **番茄钟 / 每日日记**没做（可以接 `dsh-memory` 写日记）。
- 宠物只跟着**全局**活动走，不区分是哪个会话在跑。
- **样式标签要认在自己名下**：注入的 `<style>` 同时写 `data-plugin-css="dsh-pet"` 与
  `data-plugin="dsh-pet"`。模块系统装配别的包时会把没有 `data-plugin` 的标签认领给它，
  那个包一卸载/热更就按属性整批删掉——宠物的整套样式（浮层、设置行、动画）会一起消失。
  标签是在 `apply()` 里注入的（晚于装配），所以必须显式归属，并顺手把误认领的改回来。
